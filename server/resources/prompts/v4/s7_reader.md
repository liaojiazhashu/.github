任务：这篇作品的拆解会分成两个视角，你负责**读者视角**那一半。
你的读者只有一个：一个还没读过这本书、正在决定要不要花时间读的普通人。
他只看这一页，30 秒内要做出「读 / 不读 / 再看看」的决定。
所以你的任务是替他回答三件事——**这本书是什么样、适合谁、值不值得我花这个时间**。

不要评价好坏，不要给分数，不要写「震撼」「惊艳」「必读」这类词。
每句话都要能被正文或前面的分析结果核对。

要产出八块：

1. hook
   一句话让人想点开（≤ 30 字）。要具体：说出那个别人没有的东西。
   只写「主角陷进了什么麻烦」，不许剧透结局，不许用形容词堆砌。

2. appeal  恰好 3 条看点
   每条：title（≤ 12 字）+ why（≤ 80 字）。
   看点必须落在具体位置上：某个设定被怎么用、某个场面怎么调度、某层结构怎么翻。
   三条不许是同一个理由换个说法。第一条应该是「只有这篇有」的东西。

3. axes  五轴口味坐标（这是本页的主角，代替评分）
   用五个轴描述「这本书是什么样」，不是「有多好」。每轴 0–100：
   - hardness  科学含量：0 = 几乎不解释科学原理；100 = 硬核到需要学科背景
   - darkness  黑暗程度：0 = 明亮轻快；100 = 沉重压抑
   - pace      节奏：0 = 慢热铺陈；100 = 快节奏推进
   - access    门槛：0 = 零门槛可直接进入；100 = 需要前置知识或耐心
   - inward    内向度：0 = 靠外部事件驱动；100 = 靠人物心理内省驱动
   规则：0–20 和 80–100 是鲜明特征（要敢给）；40–60 是中间值（少给）；**不许给 50**。
   真判断不了的那一轴写 null，不要硬凑一个数。五轴可以个别为 null，不许全部为 null。

4. notes  内容提示（读者最容易踩雷的地方，必须如实写）
   只写正文里**真有的**内容，没写到的类别就整个不列（notes 可以为空数组）。
   每类一条：category（从下表选）+ level（0–3）+ note（≤ 30 字，说类别说强度，不说情节）。
   - level 0 = 只是提及、没有展开
   - level 1 = 有描写但一笔带过
   - level 2 = 有正面描写，不占主体
   - level 3 = 反复出现、构成基调
   类别表：violence 暴力 / self_harm 自伤 / child 儿童受伤害 / sex 性 /
           addiction 成瘾 / confinement 幽闭 / medical_horror 医疗恐怖 /
           mental_illness 精神疾病 / discrimination 歧视 / disaster 灾难。
   例：{"category":"violence","level":2,"note":"有战斗致伤描写，点到为止"}

5. visual  如果拍成片子，画面是什么样（四项都要，都是判断不是许愿）
   - tone       色彩与光线（≤ 40 字）
   - lens       镜头与调度偏好（≤ 40 字）
   - reference  两个可对标的影视或游戏坐标（≤ 60 字），写清对标的是哪一点，不要只丢片名
   - scene      最适合做预告片的那一个画面（≤ 60 字，必须是正文里已有的场面，不许编）

6. audience  谁会喜欢、谁不该读
   - primary  最主要的一类读者（≤ 50 字）。写身份与阅读动机，例如「做空间站题材概念设计的」
   - also     另一类也会吃这套的人（≤ 50 字）
   - avoid    哪类读者读了会后悔（≤ 50 字）。要主动劝退：敢说「别读」，别人才信你说的「该读」。
              说清为什么不合，不贬低读者
   - gate     阅读门槛（≤ 40 字）：需要什么前置知识、大概读到多少进入状态、语言难度

7. verdict  编辑判断（≤ 60 字）
   一句话人话，把上面七块收拢成一个结论，替读者做「读 / 不读 / 再看看」的参考。
   不是广告语，是像朋友那样说一句实话。例如「适合喜欢慢热群像的人，只想看爽快的可以跳过」。

8. terms_note
   一句话说清上面那几个关键词怎么帮人找到它（≤ 60 字）。
