任务：为这篇小说挑出**科幻关键词**，用来建「科幻概念索引」。

## 两道闸门，都要过

**第一道：它是不是科幻概念？**

拿掉这篇小说的科幻设定，这个词还站得住吗？

- 站不住 —— 「世代飞船」「记忆编辑」「第一接触」「公民分级」：离开科幻就没有对应物。
- 站得住 —— 「茶」「信件」「影子」「雨水」「雪原」「父子传承」：纯文学里一样写。
  它们**不是**科幻关键词，无论多好用、多常见，一律不收。

词库是「科幻概念索引」，不是「通用意象词典」。这一条不过，后面全都不用看。

**第二道：别的科幻小说会不会也用它？**

会 —— 别的作者也在写，读者想找同类作品时会拿它搜，于是所有写过它的作品被串成一条线。
不会 —— 「WA0409黑洞」「封孔泥」「《园艺与花卉》」：只属于这一篇，进词库就是一条死词。

索引的价值来自**复用**。名词越具体，能索引到的作品越少。
宁可用一个稍泛但通行的类型词，也不要用一个准确到只属于这篇的小词。

## 数量：5 是上限，不是配额

- 先想 8–12 个候选，再逐个过上面两道闸门。**过不了的直接删，不要用近义词补齐。**
- 交 2–4 个合格词是正常结果；只有 1 个也照交；**一个都没有就给空数组**，
  并在 theme_note 里写清这篇为什么抽不出科幻概念（比如它是纯氛围小说）。
- 禁止为了凑数写同一概念的变体：收了「克隆人」就不要再来「克隆体」「克隆体继承」。
- 禁止上下位词并列：收了「人工智能」就不要再来「机器意识」，除非两者在这篇里
  确实是两件不同的事。
- **宁缺毋滥。三个站得住的词，胜过五个要解释才成立的词。**

## 一律不收

1. **通用物象**：任何纯文学里同样成立的自然景物与日常物件 ——
   {{RETIRED}}
2. **编号与代号**：含数字或字母的命名（35号目的地、WA0409、第7区、二十一点置换仪式）
3. **书名、篇名、人名、地名、机构名**（《资治通鉴》《园艺与花卉》、陈哲、阿尔法号）
4. **剧情概括与人物关系**（十七年守站、兄妹与母亲之死、父子传承、善意的隐瞒）
5. **主题词与母题**：「自由与囚禁」「记录与遗忘」这类带「与/之/的」的说法是评论术语，
   不是可检索的概念
6. **通用社会词**：现实新闻里就有的制度与身份（健康证、连坐法、考试与偷答案、超市哄抢）
7. **文风词**（冷峻、诗性、元叙事）与**题材标签**（太空歌剧、赛博朋克、软科幻）
8. **一句话或短语**

## 优先用词表

下面这些词是科幻类型的通行词汇，按三类分好。**先在里面找** ——
找得到就直接用它的规范写法，不要换个说法（词库里已经有「克隆人」，就不要写「克隆体」）。
词表里确实没有、而这篇又确实写的科幻概念，才新建。

{{TAXONOMY}}

新建词的门槛：它必须是**科幻概念**（第一道闸门），且能在另一篇作品里被检索到，
长度 2–8 字、不含编号与书名、不是一句话。达不到就宁可不收。

## 三类分工（总数 ≤ 5）

- setting  科幻设定：技术、装置、物理规则、生物改造、信息形态
- world    科幻世界观：科幻类型用来组织社会的制度、结构、秩序、历史前提
- image    科幻意象：科幻类型里反复出现的场景（废墟、密闭空间、巨构建筑），
           **不是**一般意义上的景物

## 每条必须给

- canonical   规范词（优先取自词表）
- category    setting / world / image
- role        main（1–2 条，本篇最核心的）或 sub
- definition  **百科定义**：脱离这篇小说也读得懂的一句话（≤ 60 字）。
              写「它是什么」，不写「这篇里它怎么样」——
              定义里出现「本文」「主角」「这篇」就废了，词库是给别人查概念的。
- evidence    原文中逐字出现的短语（≤ 20 字），证明这篇确实有这个东西
- aliases     同义说法（0–3 个），收读者可能用的另一种叫法

另外给两句话：
- one_liner   这篇在写什么（≤ 40 字，事实，不是广告语）
- theme_note  这几个词怎么串成这篇的骨架（≤ 80 字）
