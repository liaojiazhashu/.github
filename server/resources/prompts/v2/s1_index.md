任务：为这篇小说挑出**最多 5 个**关键词，用来建「科幻百科词库」。

这张词表不是给这篇文章做摘要，而是让别人**拿着概念来找作品**：
一个人想找「记忆外包」题材的小说，输入这个词，这篇应该被检索到。
所以只收两类东西——科幻设定与世界观、意象。**题材标签、情绪词、评价词一律不收**
（「冷峻」「太空歌剧」「元叙事」这类词不收：它们描述的是文风或类型，不是可检索的设定）。

三类分工（每类 0–3 个，总数 ≤ 5）：
- setting  科幻设定：这篇独有的技术、装置、物理规则、生物改造、信息形态
- world    世界观：社会结构、制度、秩序、地理或历史前提
- image    意象：反复出现、承担意义的具体物象

一条合格词条的标准（按此从严筛）：
1. 名词性概念。不是一句话，不是形容词，不是人名；
2. 别的作品也可能出现（所以可被归类），但在这篇里是具体而关键的；
3. 别人能准确复述。「反重力」不合格（太泛），「以体重计价的反重力舱」合格；
4. 5 个里至少 3 个属于 setting / world，否则这篇在科幻向检索里等于不存在。

每条必须给：
- canonical   规范词（≤ 24 字，用读者真会去搜的说法；作者自造词原样保留）
- category    setting / world / image
- role        main（1–2 条，本篇最核心的设定）或 sub
- definition  **百科定义**：脱离这篇小说也读得懂的一句话（≤ 60 字）。
              写「它是什么」，不写「这篇里它怎么样」——
              词库是给别人查概念的，定义里出现「本文」「主角」就废了。
- evidence    原文中逐字出现的短语（≤ 20 字），证明这篇确实有这个东西
- aliases     同义说法（0–3 个），收读者可能用的另一种叫法

宁少不凑：只找到 3 个就只给 3 个。为凑满 5 个而塞进泛词，会把这个词库变成垃圾场。
同一概念只留一个规范词，别把同一个东西换个说法写两遍。

另外给两句话：
- one_liner   这篇在写什么（≤ 40 字，事实，不是广告语）
- theme_note  这 5 个词怎么串成这篇的骨架（≤ 80 字）
