任务：为这篇小说挑出**最多 5 个**关键词，用来建「科幻百科词库」。

## 判据只有一条

**这个词，能不能出现在另一篇不相干的小说里？**

能 —— 「世代飞船」「记忆编辑」「第一接触」「反乌托邦」：别的作者也在写，
读者想找这类作品时会拿它去搜，于是所有写过它的作品被串成一条线。

不能 —— 「WA0409黑洞」「封孔泥」「《园艺与花卉》」「巧克力罐」：它们只属于这一篇。
放进词库，这个词底下永远只挂着一篇小说，检索功能等于零。

索引的价值来自**复用**，不来自**精确**。名词越具体，能索引到的作品越少。
所以宁可用一个稍泛但通行的大词，也不要用一个准确到只属于这篇的小词。

三个词能覆盖五篇作品，好过五个词各只覆盖一篇。

## 一律不收

1. **编号与代号**：含数字或字母的命名（35号目的地、WA0409、第7区、二十一点置换仪式）
2. **书名、篇名、人名、地名、机构名**（《资治通鉴》《园艺与花卉》）
3. **日常小道具**：任何故事里都可能出现的具体物件（巧克力罐、太阳能热水器、封孔泥、尾水洞水渍）
4. **一句话或短语**：「文字动物移动不可见」「创造文字动物的渴望条件」
5. **只在本篇成立的自造概念** —— 除非它已经是类型里的通行说法
6. **文风词**（冷峻、诗性、元叙事）与**题材标签**（太空歌剧、赛博朋克、软科幻）
7. **缝合词**：用「与」「之」「的」把两个概念拼在一起（反重力与磁悬浮）

## 三类分工（总数 ≤ 5）

- setting  科幻设定：技术、装置、物理规则、生物改造、信息形态
- world    世界观：社会结构、制度、秩序、地理或历史前提
- image    意象：母题级物象（废墟、孤岛、永夜、镜面、温室），不是具体小道具

## 每条必须给

- canonical   规范词（优先取自词表）
- category    setting / world / image
- role        main（1–2 条，本篇最核心的）或 sub
- definition  **百科定义**：脱离这篇小说也读得懂的一句话（≤ 60 字）。
              写「它是什么」，不写「这篇里它怎么样」——
              定义里出现「本文」「主角」「这篇」就废了，词库是给别人查概念的。
- evidence    原文中逐字出现的短语（≤ 20 字），证明这篇确实有这个东西
- aliases     同义说法（0–3 个），收读者可能用的另一种叫法

另外给两句话：
- one_liner   这篇在写什么（≤ 40 字，事实，不是广告语）
- theme_note  这几个词怎么串成这篇的骨架（≤ 80 字）
